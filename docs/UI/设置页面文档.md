## 2. 入口与导航模型

设置页**不是**导航栏里的可见项，而是用一个虚拟 `NavItem` 绑定到两个导航控件的 `SelectedItem`。

### 2.1 `MainViewModel`

```csharp
public NavItem SettingsNavItem { get; }   // 不在 AllViews
public SettingViewModel Settings { get; }

[ObservableProperty] private bool _isSettingsOpen;
[ObservableProperty] private NavItem? _selectedNavItem;

public void OpenSettings();
public void CloseSettings();
public ICommand ToggleSettingsCommand { get; }
```

- `SettingsNavItem`：
  - `Label = "设置"`；
  - `Icon = NavIcon.Resolve(NavIcon.Settings)`；
  - `Group = NavGroup.A`；
  - `Content = Settings`。
- 构造时保存注入的 `SettingViewModel`，再创建虚拟项。
- **不预设** `SelectedNavItem`：启动首项仍由导航控件的 `SelectedIndex=0` + `ItemsResource` 提交逻辑负责，控件再经 TwoWay 绑定回推。
- 订阅：
  - `AboutPageViewModel.OpenSettingsRequested` → `OpenSettings()`；
  - `SettingViewModel.CloseSettingViewRequested` → `CloseSettings()`。

### 2.2 打开 / 关闭

```text
OpenSettings()
 ├─ IsSettingsOpen = true
 ├─ _previousNavItem = SelectedNavItem
 └─ SelectedNavItem = SettingsNavItem

CloseSettings()
 ├─ IsSettingsOpen = false
 ├─ SelectedNavItem = _previousNavItem
 └─ _previousNavItem = null
```

- 关闭后回到打开前的那一页。
- `_previousNavItem` 为 `null`（启动即打开或没有记录）时，把 `null` 交给导航控件；控件按既有语义回退首个可见项。
- 用户直接点任一可见导航项时，控件把 `SelectedItem` 写回 `MainViewModel.SelectedNavItem`；`OnSelectedNavItemChanged` 发现不是虚拟项，关闭设置状态并清空 `_previousNavItem`。

### 2.3 关于页入口

`AboutPageView` 分割线下方是选项列表 `AboutOptions`，当前只有设置一项：

```text
[齿轮] 设置                                    >
```

- 整行 `Button`，绑定 `OpenSettingsCommand`。
- 左右图标：左 `IconSettings`，右 `IconChevronRight`。
- 行高由 `Padding="8,10"` + 内容 `MinHeight="32"` 组成（约 52）。
- 右侧图标表示动作；没有右侧图标的选项不挂 `Command`，即不可点击。
- 悬停：背景 `#0A000000`，右箭头透明度 `0.45 → 0.8` 并右移 `2px`。
- 按下：背景 `#16000000`，整行 `scale(0.985)`。

> 关于页的选项行使用本地 `ControlTheme` + 本地 `ControlTemplate`（`AboutOptionTheme` / `AboutOptionRowTemplate`），避免被 SukiUI 窗口主题的按钮模板覆盖。后续所有关于页跳转项复用同一套行样式。

### 2.4 桌面标题栏入口

`DesktopMainWindow` 标题栏右侧、最小化按钮左侧：

```xml
<Button Classes="win-btn"
        Classes.active="{Binding IsSettingsOpen}"
        Command="{Binding ToggleSettingsCommand}"
        ToolTip.Tip="设置">
    <PathIcon Data="{StaticResource IconSettings}" ... />
</Button>
```

- 打开时只提升 `Opacity`，不画矩形背景色块。
- 再点一次按 `IsSettingsOpen` 关闭。

### 2.5 导航控件绑定

两个平台都：

```xml
SelectedItem="{Binding SelectedNavItem, Mode=TwoWay}"
```

导航控件对 `SelectedItem` 的扩展语义：

- 可写、TwoWay。
- 外部项**不在** `ItemsResource` 中（设置虚拟项）：
  - `SelectedIndex = -1`；
  - 所有可见项 `IsSelected = false`；
  - 桌面指示器隐藏；
  - `SelectedItem` 保留外部项，内容区仍渲染它的 `Content`。
- 外部项**在**集合中：正常选中。
- `SelectedItem = null`：回退首个可见项；没有项时保持 `null`。
- 用户点击可见项：清掉外部选中态。
- 集合变化：保留外部项；没有外部项时走正常首项/当前索引逻辑。
- 从外部项返回可见项时，桌面指示器直接在目标项落位，不跨越中间项平移。

## 3. `SettingViewModel`

```csharp
public sealed partial class SettingViewModel : ViewModelBase
{
    public IReadOnlyList<SettingSectionGroup> Sections { get; }
    public bool HasSettings { get; }
    public bool IsEmpty { get; }
    public event EventHandler? CloseSettingViewRequested;
    public ICommand CloseCommand { get; }
}
```

- 构造注入 `ISettingService`，直接保存 `GetAllSettings()` 返回的分区。
- 对每个 `SettingItem` 订阅 `PropertyChanged`，只处理 `Value`。
- 用 `_isProcessingChange` 防重入；调用 `ChangeSettings(item)`。
- 服务异常只记日志，不向 UI 抛出。
- `CloseCommand` 触发 `CloseSettingViewRequested`，由 `MainViewModel.CloseSettings()` 负责切页。
- 集合运行期不增删，`Sections` / `Items` 使用 `IReadOnlyList`。

## 4. `SettingView`

### 4.1 总体结构

```xml
<Panel>
    <OnPlatform>
        <On Options="Windows">桌面布局</On>
        <On Options="Android">Android 布局</On>
    </OnPlatform>
</Panel>
```

两套分支各自负责标题栏与滚动结构，不共享外层 `ScrollViewer`。

### 4.2 桌面分支

```text
Grid RowDefinitions="Auto,*" Margin="24,56,24,20"
 ├─ Row 0：返回图标 + 「设置」标题
 └─ Row 1：ScrollViewer
      └─ ItemsControl（Sections）
           └─ SukiUI GroupBox（分区标题）
                └─ ItemsControl（Items）
                     └─ 行：标题/描述 + ToggleSwitch / ComboBox
```

- 顶部 `Margin="24,56,24,20"`：把返回按钮放到 `DesktopMainWindow` 标题栏拖动层下方，避免点击被拖动层截走。
- 返回按钮：`Button.setting-back`，32×32，透明背景/无边框，只显示 `IconBack`。
- 分区：`SukiUI.Controls.GroupBox`，`Header="{Binding Title}"`。
- Toggle：Avalonia `ToggleSwitch`，默认走 Suki 主题，`IsChecked="{Binding BoolValue, Mode=TwoWay}"`。
- SingleChoice：`ComboBox`，`ItemsSource="{Binding OptionTitles}"`、`SelectedItem="{Binding SelectedOptionTitle, Mode=TwoWay}"`。
- 行间 `Border` 细线；描述由 `HasDescription` 控制显隐。
- 空态：「暂无可配置的设置项」。

### 4.3 Android 分支

```text
SettingSliverPage Header="设置" IsBackVisible="True" BackCommand="{Binding CloseCommand}"
 └─ StackPanel
      └─ ItemsControl（Sections）
           └─ CherylUI GroupBox
                └─ FormFieldSwitch / FormFieldPicker + 描述 + HorizontalSeparator
```

- `SliverPage` 自带 `ScrollViewer`、折叠标题栏、背景模糊与滚动动画；**不要再套一层 ScrollViewer**。
- 内置返回按钮默认调用 `MobileNavigation.Pop()`，而设置页不在 `MobileNavigation` 栈里；CherylUI 2.1.2 起 `SettingSliverPage` 可重写 `GoBack`，改为执行 `BackCommand`（绑定 `CloseCommand`），返回按钮本身仍由 SliverPage 绘制。
- `SettingSliverPage` 用 `StyleKeyOverride` 沿用基类的模板与样式，派生类不需要复制 SliverPage 的 XAML。
- 分区：`CherylUI.Controls.GroupBox`。
- Toggle：`FormFieldSwitch`，`Title` + `IsChecked="{Binding BoolValue, Mode=TwoWay}"`。
- SingleChoice：`FormFieldPicker`，`Items="{Binding OptionTitles}"`、`SelectedItem="{Binding SelectedOptionTitle, Mode=TwoWay}"`、`DialogTitle`、`DialogSubTitle`。
- 描述：FormField 下方 `TextBlock`，`HasDescription` 控制显隐。
- 行间：`CherylUI.HorizontalSeparator`。
- 空态：「暂无可配置的设置项」。

### 4.4 平台控件对照

| 用途 | 桌面（SukiUI 优先） | Android（CherylUI 优先） |
| --- | --- | --- |
| 页面容器 | `Grid` + 自定义返回/标题 + `ScrollViewer` | `SettingSliverPage IsBackVisible=True` |
| 分区卡片 | `SukiUI.Controls.GroupBox` | `CherylUI.Controls.GroupBox` |
| Toggle | `ToggleSwitch`（Suki 主题） | `FormFieldSwitch` |
| SingleChoice | `ComboBox`（Suki 主题） | `FormFieldPicker` |
| 行分隔 | `Border` 细线 | `HorizontalSeparator` |
| 返回按钮 | `Button.setting-back` + `PathIcon` | SliverPage 内置按钮，`GoBack` 执行 `BackCommand` |
| 空态 | 分支内 `TextBlock` | SliverPage 内容内 `TextBlock` |

### 4.5 数据模板

`SettingView.Resources`：

- `DesktopSettingItemTemplate`（`x:DataType="settings:SettingItem"`）；
- `AndroidSettingItemTemplate`。

`SettingViewModel.Sections` 是 `IReadOnlyList<SettingSectionGroup>`，`Items` 是 `IReadOnlyList<SettingItem>`；分区模板直接写在各自 `OnPlatform` 分支里。

### 4.6 最小使用

生产环境不需要手动创建 `SettingView`：由 `ViewLocator` 按 `SettingsNavItem.Content`（`SettingViewModel`）解析。

如果只在测试/设计器里单独挂载：

```csharp
var viewModel = new SettingViewModel(settingService);
var view = new SettingView { DataContext = viewModel };
```

## 5. 交互细节

### 5.1 设置项值变化

```text
ToggleSwitch / FormFieldSwitch / ComboBox / FormFieldPicker
  └─ SettingItem.BoolValue / SelectedOptionTitle
       └─ SettingItem.Value
            └─ SettingViewModel 监听 PropertyChanged
                 └─ ISettingService.ChangeSettings(item)
                      ├─ ReceiveSettingChanges
                      └─ 同步原子写 settings.json
```

### 5.2 关闭设置页

```text
桌面返回按钮 / Android SliverPage 内置返回
  └─ SettingViewModel.CloseCommand
       └─ CloseSettingViewRequested
            └─ MainViewModel.CloseSettings()
                 ├─ IsSettingsOpen = false
                 └─ SelectedNavItem = 打开前的页面
```

### 5.3 空态

- `Sections.Count == 0` 时显示「暂无可配置的设置项」。
- 生产代码默认没有 `ISetting` 实现，因此首次进入为空态；注册方接入后自动出现分区。

## 8. 维护注意

- **不要给设置页单独的 ViewModel 实例**：`MainViewModel.Settings`、`SettingsNavItem.Content`、`SettingView.DataContext` 必须是同一个单例。
- **不要恢复启动首项选择**：首项由导航控件负责；`MainViewModel` 只在关闭设置且无记录时置空。
- **不要给设置虚拟项加进 `AllViews`**：它不应出现在导航栏。
- **不要重写 SliverPage 的标题栏/滚动结构**：折叠、模糊、滚动动画由控件提供；返回动作通过 `SettingSliverPage.BackCommand` 接入。
- **返回按钮位置**：桌面标题栏拖动层覆盖内容顶部，设置页桌面分支保留顶部 `56` 的外边距。
- **按钮样式覆盖**：关于页选项行同时使用本地 `ControlTheme`/`ControlTemplate` 和局部 `Style`；CherylUI 的隐式 `Button` 样式会设置 `Accent` 背景，只有局部 `Style` 能稳定覆盖。
- **Android 返回**：不要改用 `MobileNavigation.Push`；设置页由 `SelectedItem` 直接渲染，返回执行 `CloseCommand` 切回 `SelectedNavItem`。
- **`FormFieldPicker` 限制**：只接受 `ObservableCollection<string>`，因此 `SettingItem.OptionTitles` 保留为可观察集合；值/显示映射仍以 `Options` 为准。
